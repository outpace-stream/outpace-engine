# Outpace 1.3.0

See the [GitHub Release](https://github.com/outpace-stream/outpace-engine/releases/tag/v1.3.0)
for publication status and downloads.

## AceStream compatibility

The supported AceStream HTTP routes, including `/ace/getstream`, `/ace/manifest.m3u8`
and `/server/api`, are enabled by default. Set `OUTPACE_ACE_COMPAT=0` and restart
the engine or recreate its container to disable them. If you copy the new Compose
environment example, set that variable to `0` there to preserve a previous opt-out.
Stream-name search remains opt-in. See [PR #535](https://github.com/outpace-stream/outpace-engine/pull/535).

## Other changes

- Added x86-64 Android engine builds alongside the ARM builds.
- Added Bouncecast and broadcast catalog registration.
- Improved DHT bootstrap recovery and live playback startup.
- Improved engine diagnostics for panics and fatal exits.
